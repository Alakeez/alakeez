===========================
Master Courses
===========================

Courses completed as part of the Master’s program in Data Science and Advanced Analytics at Nova IMS, University of Lisbon (2021/2022), with projects hosted on this GitHub:

1. **Data Mining** – Customer segmentation and clustering using K-Means, Hierarchical Clustering, DBSCAN, and Self-Organizing Maps (SOM) in Python.
   - Repository: [data-mining-customer-clustering](https://github.com/Alakeez/data-mining-customer-clustering)

2. **Machine Learning** – Final project covering supervised and unsupervised learning techniques, model evaluation, and practical implementations.
   - Repository: [machine-learning-project](https://github.com/Alakeez/machine-learning-project)

3. **Big Data Modelling and Management** – Handling, processing, and modeling large datasets using modern big data tools.
   - Repository: [big-data-modelling-management](https://github.com/Alakeez/big-data-modelling-management)

4. **Storing and Retrieving Data** – Project for database design, storage optimization, and data retrieval techniques.
   - Repository: [storing-retrieving-data](https://github.com/Alakeez/storing-retrieving-data)

5. **Deep Learning** – Predicting artist popularity using deep learning techniques and neural networks.
   - Repository: [deep-learning-artist-prediction](https://github.com/Alakeez/deep-learning-artist-prediction)

6. **Data Visualization & Analytics App** – Interactive visualization project using Python for data insights.
   - Repository: [data-visualization-app](https://github.com/Alakeez/data-visualization-app)
